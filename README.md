# Payment Gateway Checkout

Interview take-home assignment built with React, Vite, Tailwind CSS and Lucide React.

## Features
- Card, UPI and Net Banking payment methods
- Live validation and input formatting
- Luhn card-number validation
- Expiry and CVV validation
- Responsive checkout layout
- Order summary with discount and tax
- Mock loading, success and error states
- Duplicate-payment prevention while processing
- Accessible labels and clear UX

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Push to GitHub and import the repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.
